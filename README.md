## 🏘️ Current Project

### AI Agent Town

I am currently studying and developing a project inspired by Stanford's “Generative Agents,” with the goal of creating a virtual world inhabited by multiple autonomous agents.

Topics I plan to explore include:

- Long-term memory and experience retrieval for agents
- Autonomous planning based on goals and environmental context
- Conversations, relationships, and collaboration between multiple agents
- The lasting impact of character behavior on the virtual world
- How AI NPCs respond to scripted and random events
- What happens when AI NPC memories can be freely edited

> The project is still in the learning and exploration stage. I plan to open-source it once it becomes sufficiently complete and reusable.
